Optional: External Google Drive Auto-Backup (Apps Script)

For an extra disaster-recovery copy in a separate Drive file, paste this in Google Sheet → Extensions → Apps Script and add a Daily Time Trigger:

function nightlyDriveBackup() { var ss = SpreadsheetApp.getActiveSpreadsheet(); var folder = DriveApp.getFoldersByName("Godrej_Backups").hasNext() ? DriveApp.getFoldersByName("Godrej_Backups").next() : DriveApp.createFolder("Godrej_Backups"); var dateStr = Utilities.formatDate(new Date(), "Asia/Kolkata", "yyyy-MM-dd"); DriveApp.getFileById(ss.getId()).makeCopy("Godrej_Inventory_Backup_" + dateStr, folder); }
